# McGrath

> McGrath Estate Agents is one of Australia's largest residential real estate brokerage networks — founded in Sydney in 1988 by John McGrath, operating roughly 118 company-owned and franchise offices across New South Wales, Queensland, the ACT, Victoria and Tasmania, and acquired in June 2024 by a Knight Frank Australia / Bayleys consortium for A$95.5m (delisted from the ASX on 28 June 2024). McGrath publishes **no API**. This file is generated by API Evangelist from the public record; McGrath does not publish an llms.txt of its own (https://www.mcgrath.com.au/llms.txt returns 404).

## What an agent needs to know first

- There is no developer portal, no API documentation, no OpenAPI/AsyncAPI/GraphQL/OData surface, no SDK, no MCP server and no sandbox. The `api.`, `apis.`, `developer.`, `developers.`, `docs.`, `feeds.`, `data.` and `portal.` subdomains of `mcgrath.com.au` do not resolve.
- `www.mcgrath.com.au` sits behind a Vercel Security Checkpoint that returns **HTTP 429** with an HTML challenge to scripted clients on every path, including `/robots.txt` and the site root. An unattended agent cannot read this site without executing a browser challenge.
- McGrath is on the **demand side** of the Australian property value chain: it is a brokerage that syndicates listings into the REA Group (realestate.com.au) and Domain portal duopoly, settles over the PEXA electronic conveyancing network, and consumes valuation data from PropTrack and CoreLogic. It produces none of those rails.
- **RESO does not apply.** RESO Web API and Data Dictionary certification are driven by NAR policy and enforced through MLS membership in North America. Australia has no MLS and no RESO equivalent; McGrath holds no certification, publishes no OData `$metadata`, and never references the RESO Universal Property Identifier.
- To obtain McGrath listing data in machine-readable form, an integrator must go around McGrath — to REA Group or Domain (commercial partner-only APIs), to CoreLogic or PropTrack for property and valuation records, or to PEXA for transaction/settlement rails (PEXA gates its developer portal behind a signed PEXA API Agreement).

## Machine-readable surfaces

- [robots.txt](https://www.mcgrath.com.au/robots.txt): the only interoperability standard McGrath demonstrably implements. Under RFC 9309 group-matching rules the named AI crawlers (GPTBot, ChatGPT-User, OAI-SearchBot, ClaudeBot, PerplexityBot, Google-Extended, CCBot, Bytespider, Applebot) are disallowed only from Google Maps JS/RPC paths; the `/properties/` and `/search/` disallows apply solely to `User-agent: *`.
- Sitemaps: twelve XML sitemaps declared in robots.txt — general, agents, articles, campaigns, media-releases, research, offices, projects, properties-buy, properties-sold, properties-rent, properties-leased.
